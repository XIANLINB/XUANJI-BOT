## 一、项目概述

### 1.1 是什么

璇玑（XuanJi）是一个基于 **Java 25 + Spring Boot 4.0.6** 的多平台机器人开发框架，参考 **AstrBot / Koishi / OneBot / 伊蕾娜(ElainaBot)** 的设计理念：

- **多平台**：QQ 官方 Bot API（WebSocket / Webhook 双模式）+ OneBot v11（NapCat 等）
- **多机器人**：一个框架同时管理 N 个机器人，互相独立、各自落库
- **插件化**：PF4J 插件体系 + `@Command` 注解语法糖 + **热加载**（改插件不重启）
- **可视化控制台**：Vue3 + Naive UI 全中文管理后台
- **三级配置**：全局 / 机器人 / 群 粒度，改完即时生效

### 1.2 最终规模

| 指标 | 数值 |
|---|---|
| Maven 模块 | 9 个（api / sdk / core / adapter-qqbot / adapter-onebot / console-server / console / plugin-demo / starter） |
| Java 源文件 | **212 个**（api 52 / sdk 10 / core 42 / qqbot 69 / onebot 20 / console-server 11 / starter 8） |
| 自动化测试 | **60 个全绿**（core + qqbot + onebot） |
| 数据库表 | 框架库 11 表 + 平台共享库 2×2 表 + per-bot 实例库 2×5 表 |
| 前端页面 | 14 个 Vue 视图（仪表盘/机器人/消息/事件/群/好友/数据库/健康/日志/插件/权限/OneBot/设置/首启引导） |
| 插件 | demo-plugin v1.1.0（20+ 命令覆盖全部语法糖） |

## 三、核心能力清单（按验收域）

### 3.1 平台接入（Q / N / W 域）

- ✅ **QQ 官方**：WebSocket（自动重连/心跳/分片）+ Webhook（Ed25519 验签/密钥注销）；AccessToken 缓存+401 重试；消息收发全量（文本/MD/Ark/键盘/图片/语音/视频/文件/卡片/撤回）；184 错误码枚举
- ✅ **OneBot v11**：正/反向 WS（Bearer 鉴权/X-Self-ID）+ 全量事件（message/notice/request/meta_event 各 sub_type）+ 全量 API（群管/好友/禁言/踢人）
- ✅ **双模式回环验证**：隔离 WS 客户端（带 mask 帧）推假事件，端到端进统一 BotPipeline，零真实连接

### 3.2 消息链路（G 域）

- ✅ **Pipeline 9 阶段**：waking-check → whitelist → dedup → rate-limit → content-safety → pre-process → dispatch → result-decorate → respond（横切只存在于 Pipeline 的铁律）
- ✅ **@Command 语法糖**：scope(GROUP/PRIVATE/BOTH) / @Arg 独立游标 / startWith 前缀 / roles 权限过滤 / media=NEED 媒体订阅（纯图片 content="" 也能命中）/ platforms 平台白名单
- ✅ **媒体五态归一化**：URL/FILE_PATH/BASE64/DATA_URI/PLATFORM_ID，`m.resolve(platform)` 平台无关
- ✅ **消息落库**：IN/OUT 双向，per-bot `qqbot_message` 表，控制台方向列真实

### 3.3 数据与存储（K 域）

- ✅ **三级库隔离**：框架库（xuanji_* 11 表）/ 平台共享库（qqbot_bot/botinfo）/ per-bot 实例库（group/member/user/message/event 5 表）
- ✅ **per-bot 化**：每个机器人独立 H2 文件，bot_id 逻辑关联，删机器人完整清理（停 WS→反注册→删库→删目录）
- ✅ **自动同步**：群消息→ensureGroup+ensureGroupMember（带昵称/角色）；C2C→ensureUser；事件→insertEvent
- ✅ **时间字段统一**：100% BIGINT epoch 秒，走 TimeUtils，禁止散写
- ✅ **升级兼容**：CREATE TABLE IF NOT EXISTS + migrateLegacyTables（v3.2→v3.3 实测迁移）

### 3.4 权限体系（P 域）

- ✅ **等级矩阵**：NONE < BLACKLIST < MEMBER < ADMIN < GROUP_OWNER < BOT_MASTER，rank() 比较
- ✅ **黑名单一票否决**（主人也拦）+ **主人 BOT_MASTER 放行**（每 bot 唯一，控制台可设）
- ✅ **命令级角色过滤**：`roles={"owner","admin"}` + @RequireRole 等级比较
- ✅ **webhook 兜底**：sender 为 null 时从 platformData 提取 member_openid（黑名单在 webhook 下也生效）
- ✅ **控制台权限页**：主人 CRUD + 黑名单增删（按 id 删，绕开 SQL NULL 陷阱）

### 3.5 插件系统（G / P3-G 域）

- ✅ **PF4J 隔离**：独立 ClassLoader + Spring 子容器，插件零依赖框架内部
- ✅ **热加载**：改 jar → 覆盖 plugins/ → 控制台点热加载 → 不重启生效；持久态保留；多插件互不影响
- ✅ **Windows jar 锁破解**：CopyingJarPluginLoader 复制到 `.work/` 加载副本，原 jar 可随时覆盖
- ✅ **插件-机器人绑定**：绑定后仅指定 bot 生效（isAllowedForBot）
- ✅ **插件启停**：完整生命周期（onEnable/onDisable 钩子 + 持久态 + 指令重注册）

### 3.6 控制台（K / 前端域）

- ✅ **14 个页面**：仪表盘/机器人/消息/事件/群/好友/数据库/健康/日志/插件/权限/OneBot/设置/首启引导
- ✅ **运行设置**：作用域选择器（全局/机器人/群）+ 类型化控件（bool 开关/number/textarea）+ 默认值 placeholder + 一键重置（单项/全部）
- ✅ **忽略机器人消息**：三级粒度（全局/bot/群），author.bot=true 判定，只记录不处理
- ✅ **健康页**：熔断状态/WS 连接（READY||CONNECTED 修正）/慢阶段统计/去重命中/插件超时
- ✅ **首启引导**：6 位口令 PBKDF2 加盐哈希 + 可跳过绑定机器人

### 3.7 性能与运维（⑤ / M 域）

- ✅ **HikariCP 连接池**：per 库独立小池 + AUTO_SERVER=TRUE，dispatch 700-900ms → 显著下降
- ✅ **出站节奏**：per-bot 串行队列 + 可配 pace_ms（Sleeper/clock 注入，毫秒级测试）
- ✅ **限频配置驱动**：默认不限制，`framework.rate_limit.enabled` 或 bot 级开关开启
- ✅ **熔断**：按 AppID 独立熔断（阈值/冷却可配）
- ✅ **启动打印控制台地址**：ApplicationReadyEvent + Environment

### 3.8 交付与文档（本次收官）

- ✅ **小白部署**：`打包发布包.bat` 一键生成发布包（mvn → jdeps → jlink 裁剪 JRE ~60MB → 组装）——用户零 Java 环境双击 `start.bat` 即用，实测 3.1s 启动

- ✅ **docs 整理**：用户手册/开发文档/历史归档三分类 + 索引

## 四、关键事故与复盘（血泪教训）

| # | 事故 | 根因 | 修复 | 教训 |
|---|---|---|---|---|
| 1 | **core 误删事故**（08-05） | `git rm` 连带删除整个模块目录；`checkout-index -a -f` 回退全部未提交改动 | CFR 反编译恢复 + 记忆重建 + IDEA Local History 校对 | 沙箱绝不用 git rm；删除用 mv 同盘 rename |
| 2 | **@Command 语法糖整体丢失**（08-06） | 事故恢复遗漏：CommandFilter.java（untracked）被删 + register() 回退旧版 | 重建 P2-F 全套 | 未提交改动是最大风险，及时 git commit |
| 3 | **@Scheduled cron + initialDelay 启动崩溃** | Spring cron 触发器不支持 initialDelay | 去掉 initialDelay，启动清理挪构造器 | 新注解参数先查契约 |
| 4 | **媒体下载每次必失败** | `createTempFile` 已建文件 + `CREATE_NEW` 再开 → 必然 FileAlreadyExistsException（被 catch 静默吞掉，无日志） | CREATE_NEW → WRITE + 全失败路径加日志 | 经典 Java 坑；**异常绝不能静默吞** |
| 5 | **多机器人出站取错凭证（11255）** | ThreadLocal 上下文不跨出站线程 → 回退 findAll 取错 token | runWithRobotContext 显式重建 | ThreadLocal 不跨线程，异步任务必须显式传上下文 |
| 6 | **webhook 限频失效（安全漏洞）** | webhook 事件 sender 运行时为 null → WhitelistStage 直接放行 | platformData 兜底提取 member_openid | sender==null 不能静默放行 |
| 7 | **重启后机器人未注册** | XuanjiBotRunner 只读 yaml，webhook 机器人重启丢注册 | 启动时从库合并 ONLINE 机器人 | 注册真相源应持久化在库 |
| 8 | **删机器人重加后表不建** | instanceSchemaReady 内存缓存未在删除时失效 | deleteBot 清缓存 | 内存缓存与磁盘删除必须同步 |
| 9 | **bat 双击闪退** | bat 含中文（UTF-8），cmd 按 GBK 解析 → 语法错误秒退 | bat 100% ASCII + 环境探测 | Windows cmd 脚本必须纯 ASCII |
| 10 | **H2 列名大写契约** | H2 返回大写字段（GROUP_ID），前端用小写 → 全 undefined | 前端大写优先兼容 | 跨 bot 聚合接口取值必须大写优先 |
