# 璇玑（XuanJi）插件开发完整指南

> 面向插件开发者。本文档与 Web 控制台「插件开发指南」页（开发指南/事件/动作/注解 四 Tab）内容一致并更完整。
> 完整可运行示例请直接看仓库自带的 **群管插件** `xuanji-plugin-groupadmin`（禁言/撤回/针对撤回/入群审批），以及 **接口测试插件** `xuanji-plugin-test`。

---

## 一、插件是什么

插件是扩展机器人能力的单元——一个普通的 JAR 包，放入运行目录 `plugins/` 即可被框架加载。**改插件不用重启框架**，控制台「插件管理」点热加载即可。

插件开发的核心心智：**框架只负责解析、过滤、下发完整字段，业务判定由插件自己实现**。插件方法里注入 `PluginServices` 一行调用框架能力，返回类型化对象（告别裸 JSON）。

## 二、目录结构与工程配置

一个插件 = 一个 Maven 模块：

```
xuanji-plugin-xxx/
├── pom.xml                           # 依赖 xuanji-sdk / xuanji-api（provided）
└── src/main/java/.../XxxPlugin.java  # 插件主类
```

`pom.xml` 关键点：

```xml
<dependencies>
    <!-- 两个框架依赖都必须 provided：运行时由框架提供 -->
    <dependency>
        <groupId>XuanJi</groupId><artifactId>xuanji-api</artifactId>
        <version>1.3.1-SNAPSHOT</version><scope>provided</scope>
    </dependency>
    <dependency>
        <groupId>XuanJi</groupId><artifactId>xuanji-sdk</artifactId>
        <version>1.3.1-SNAPSHOT</version><scope>provided</scope>
    </dependency>
</dependencies>
...
<plugin>
    <artifactId>maven-jar-plugin</artifactId>
    <configuration>
        <archive>
            <manifestEntries>
                <Plugin-Id>groupadmin-plugin</Plugin-Id>          <!-- 插件唯一 ID -->
                <Plugin-Class>XuanJi.plugin.groupadmin.GroupAdminPlugin</Plugin-Class> <!-- 入口类 -->
            </manifestEntries>
        </archive>
    </configuration>
</plugin>
```

> 实际包名是 `XuanJi.api.*` / `XuanJi.sdk.*`（大写 XuanJi）。

## 四、命令：@Command

`@Command` 是"一条消息 → 一个方法"的语法糖（内部自动匹配 `@GroupMessage`/`@PrivateMessage` + 过滤条件）。

### 4.1 作用域

`Command.Scope`：`GROUP`（仅群聊）/ `PRIVATE`（仅单聊）/ `BOTH`（默认，群聊+单聊）。

```java
@Command(value = "群聊命令", scope = Command.Scope.GROUP)
public String groupOnly(GroupMessageEvent e) {
    return "群聊专属，当前群：" + e.getGroupId();
}

@Command(value = "私聊命令", scope = Command.Scope.PRIVATE)
public String privateOnly(PrivateMessageEvent e) {
    return "单聊专属，你的 ID：" + e.getSenderId();
}

@Command(value = "ping", scope = Command.Scope.BOTH)
public String ping(Bot bot) {
    return "pong！机器人：" + bot.selfId();
}
```

**方法返回值 String 会作为回复发给用户；返回 null 则不回复。**

### 4.2 触发方式

```java
// 触发词（value）支持正则，如 "签到|打卡"；空串 = 匹配所有消息（配合 startWith 等）
@Command(value = "签到", scope = Command.Scope.GROUP)
public String sign(GroupMessageEvent e) { return "签到成功"; }

// 前缀触发：以 "!" 开头即命中
@Command(value = "", scope = Command.Scope.BOTH)
@MessageFilter(startWith = "!")
public String prefix(MessageEvent e) { return "前缀命令：" + e.getPlainText(); }

// 必须 @机器人 才触发
@Command(value = "你好", scope = Command.Scope.GROUP, at = AtMode.NEED)
public String hi(GroupMessageEvent e) { return "你好！"; }

// 限定角色：仅群主/管理员
@Command(value = "#禁言", scope = Command.Scope.GROUP, roles = {"owner", "admin"})
public String mute(GroupMessageEvent e) { return "有权限"; }

// 媒体订阅：纯图片/语音/视频消息无需命令词直接命中
@Command(value = "看图", scope = Command.Scope.GROUP, media = MediaMode.NEED, mediaTypes = {MediaType.IMAGE})
public String image(GroupMessageEvent e) { return "收到一张图片"; }
```

### 4.3 命令参数：@Arg

框架自动从消息里解析参数（空格分隔的 token，类型自动转换），**QQ 的 @占位已自动剥掉**，无需手写正则。

```java
// 必填参数
@Command(value = "查群", scope = Command.Scope.BOTH)
public String group(@Arg(value = "群号", required = true) String gid) {
    return "查询群：" + gid;
}

// 可选参数：缺省为 null
@Command(value = "问候", scope = Command.Scope.BOTH)
public String greet(@Arg(value = "名字", required = false) String name) {
    return name == null ? "你好！" : "你好，" + name + "！";
}

// rest=true：取剩余全部（含空格），必须作为最后一个参数
@Command(value = "回声", scope = Command.Scope.BOTH)
public String echo(@Arg(value = "内容", required = true, rest = true) String content) {
    return "你说的是：" + content;
}

// 数字类型自动转换：int / long / Integer 等
@Command(value = "#禁言", scope = Command.Scope.GROUP, roles = {"owner", "admin"})
public String mute(GroupMessageEvent e, PluginServices svc,
                   @Arg(value = "分钟", required = false) Integer minutes) {
    // 分钟缺省逻辑由插件处理；分钟→秒的换算由框架适配器完成
    List<String> targets = e.getMentionedUserIds();   // 框架已过滤机器人/自己
    if (targets.isEmpty()) return "用法：#禁言 @成员 <分钟>";
    return svc.muteGroupMembers(e.getBotId(), e.getGroupId(), targets,
            minutes == null ? 10 : minutes).message();
}
```

### 4.4 参数注入

命令/事件方法可以注入以下类型参数（框架自动装配）：

| 参数类型 | 说明 |
|---|---|
| `GroupMessageEvent` / `PrivateMessageEvent` / `MessageEvent` | 当前消息/事件（字段见「六、事件」） |
| `Bot` | 当前机器人（reply / sendGroup / selfId 等便捷方法） |
| `PluginStorage` | 持久化 KV 存储（按插件隔离，落库 `xuanji_plugin_kv`） |
| `PluginConfig` | 读取配置面板（PluginConfigProvider）配置的值 |
| `PluginServices` | 框架能力门面：发消息 / LLM / 群管 / 信息查询（见「七、动作」） |

## 五、消息监听与事件

### 5.1 收到消息

```java
// 收到群消息（不抢 @Command，order 靠后）
@GroupMessage(order = 200)
public void onGroupMsg(GroupMessageEvent e, Bot bot) {
    if (e.getPlainText().contains("群消息")) bot.reply("收到群消息：" + e.getPlainText());
}

// 收到单聊消息
@PrivateMessage(order = 200)
public void onPrivateMsg(PrivateMessageEvent e, Bot bot) {
    if (e.getPlainText().contains("私聊消息")) bot.reply("收到单聊消息");
}

// 任意消息监听（群+私聊，原始监听）
@OnMessage(priority = 80)
public void onAny(MessageEvent e) {
    System.out.println("任意消息：" + e.getPlainText());
}
```

### 5.2 系统事件

```java
// 群事件：成员进群/退群/入群申请等，用 e.getEventType() 区分
@GroupEvent(order = 10)
public void onGroupEvent(GroupMessageEvent e, PluginServices svc, PluginConfig cfg) {
    String et = e.getEventType();
    if ("GROUP_MEMBER_ADD".equals(et)) {
        svc.sendToGroup(e.getBotId(), e.getGroupId(),
            XuanJiMessage.text(cfg.getString("welcomeWord", "欢迎新成员！")));
    }
}

// 私聊事件：好友添加/删除
@PrivateEvent(order = 10)
public void onPrivateEvent(PrivateMessageEvent e) {
    System.out.println("私聊事件：" + e.getEventType());
}
```

### 5.3 事件注解总览

| 注解 | 监听什么 | 事件对象 |
|---|---|---|
| `@GroupMessage` | 群聊消息 | `GroupMessageEvent` |
| `@PrivateMessage` | 单聊消息 | `PrivateMessageEvent` |
| `@OnMessage` | 任意消息（群+私聊，原始监听） | `MessageEvent` |
| `@GroupEvent` | 群系统事件（进群/退群/入群申请…） | `GroupMessageEvent`（`getEventType()` 区分） |
| `@PrivateEvent` | 私聊系统事件（好友添加/删除） | `PrivateMessageEvent`（`getEventType()` 区分） |

### 5.4 群事件类型清单

用 `e.getEventType()` 区分：

| 事件类型 | 触发时机 | 关键字段 |
|---|---|---|
| `GROUP_MEMBER_ADD` | 成员进群 | groupId / senderId / senderName |
| `GROUP_MEMBER_REMOVE` | 成员退群 | groupId / senderId |
| `GROUP_JOIN_REQUEST` | 用户申请入群 | groupId / senderId + `getJoinRequestInfo()` 全量字段 |
| `GROUP_ADD_ROBOT` | 机器人被拉入群 | groupId |
| `GROUP_DEL_ROBOT` | 机器人被移出群 | groupId |
| `GROUP_MSG_REJECT` | 群消息接收被关闭 | groupId |
| `GROUP_MSG_RECEIVE` | 群消息接收被开启 | groupId |

### 5.5 消息事件对象字段

#### MessageEvent（接口，群聊+单聊通用）

| 方法 | 返回 | 说明 |
|---|---|---|
| `getMessageId()` | String | 消息 ID |
| `getContent()` | String | 原始内容（含 @ 占位） |
| `getPlainText()` | String | 纯文本（已剥掉所有 @占位） |
| `getPlatform()` | String | 平台标识（qq / onebot…） |
| `getChain()` | XuanJiMessage | 解析后的消息链 |
| `getStripped()` | Stripped | 已裁剪命令前缀的文本 |
| `getBotKey()` / `getUnifiedMsgOrigin()` | String | 机器人键 / 消息来源 |

#### GroupMessageEvent（群聊消息 / 群事件）

| 方法 | 返回 | 说明 |
|---|---|---|
| `getGroupId()` | String | 群 openid |
| `getSenderId()` | String | 发送者 member_openid |
| `getSenderName()` | String | 昵称 |
| `getSenderRole()` | String | owner / admin / member |
| `getMentionedUserIds()` | List\<String\> | **框架已过滤**（不含机器人/自己）的可操作目标，禁言/@ 命令直接用 |
| `getMentionedUsers()` | List\<Mention\> | 过滤后的目标（含角色） |
| `getAllMentions()` | List\<Mention\> | 原始 @ 列表（含机器人与自己） |
| `isAtBot()` | boolean | 是否 @ 了机器人 |
| `getEventType()` | String | 群事件类型（普通消息为空串） |
| `getBotId()` | String | 事件所属机器人（多机器人必用） |
| `getJoinRequestInfo()` | JoinRequest | 入群申请完整字段（仅 `GROUP_JOIN_REQUEST`） |
| `getStripped()` / `getChain()` | — | 裁剪前缀文本 / 消息链 |

`Mention`：`record Mention(String userId, boolean bot, boolean isYou, String role)`
（`userId`=成员 openid，`bot`=是否机器人，`isYou`=是否机器人自己，`role`=成员角色）

#### PrivateMessageEvent（单聊消息 / 私聊事件）

`getMessageId()` / `getSenderId()` / `getSenderName()` / `getMessageType()` / `getPlainText()` / `getChain()` / `getStripped()` / `getEventType()`

#### Stripped（已裁剪命令前缀）

`record Stripped(String content, String prefix, boolean appel, boolean hasAt, boolean atSelf)`

### 5.6 入群申请事件（GROUP_JOIN_REQUEST）

`e.getJoinRequestInfo()` 返回 `JoinRequest`。框架已解析 verify_info 两种数据源差异（事件推送 `verify_message` / 列表拉取 `admin_review_qa`），**审批判定由插件实现**。

| 方法 | 返回 | 说明 |
|---|---|---|
| `memberOpenid()` | String | 申请者 openid |
| `username()` | String | 昵称 |
| `applyAt()` / `applySource()` | String | 申请时间 / 来源（self_apply…） |
| `joinRequestId()` | String | 申请 ID（**审批必传**） |
| `isQaMode()` | boolean | 是否设置了入群问题 |
| `getQuestion()` / `getAnswer()` | String | 问题 / 申请者填写的答案 |
| `getVerifyMessage()` | String | 验证消息（无问题时即填写内容） |
| `getMethod()` | String | verify_message / admin_review_qa |
| `verifyInfo()` / `verifyParsed()` | Map | 平台原始 / 框架解析后的验证信息 |

## 六、消息构建全类型（XuanJiMessage）

```java
// ① 纯文本
XuanJiMessage.text("你好");
XuanJiMessage.builder().text("你好").build();

// ② Markdown
XuanJiMessage.builder().markdown("**加粗**、*斜体*、`代码`、- 列表项").build();
// 或：bot.replyMarkdown("**加粗**") / bot.sendGroupMarkdown(groupId, "**加粗**")

// ③ ARK 卡片（模板卡片：templateId + 参数 JSON）
XuanJiMessage.builder().add(new XuanJiMessageElement.Ark(25, null)).build();
// 或：bot.replyArk(25, "{\"desc\":\"内容\"}");

// ④ 富媒体：图片 / 语音 / 视频 / 文件（URL 或本地文件引用）
XuanJiMessage.builder()
    .image("https://example.com/a.png")                          // 图片
    .add(new XuanJiMessageElement.Voice("https://.../a.mp3", 10))  // 语音（时长秒）
    .add(new XuanJiMessageElement.Video("https://.../a.mp4"))      // 视频
    .add(new XuanJiMessageElement.File("https://.../a.pdf", "a.pdf", 1024))  // 文件
    .build();

// ⑤ 组合消息：文本 + @ + 表情 + 回复
XuanJiMessage.builder()
    .text("你好 ")
    .at(userId)         // @某人
    .face(1)            // 表情
    .reply(msgId)       // 回复指定消息
    .build();

// ⑥ 键盘按钮（markdown 附键盘，详见《QQ内嵌键盘按钮使用指南》）
XuanJiMessage.builder().markdown("点按钮").add(new XuanJiMessageElement.Keyboard(keyboardJson)).build();
```

**发送方式**：

```java
// 回复当前消息（最简单）：方法返回 String 自动回复，或
bot.reply("文本");
bot.replyMarkdown("**markdown**");
bot.replyImage(url);
bot.replyVideo(url);
bot.replyArk(templateId, arkJson);

// 主动发送（botKey 必须是事件所属机器人，不能传空串！）
svc.sendToGroup(bot.selfId(), groupId, XuanJiMessage.text("主动消息"));
bot.sendGroup(groupId, "文本");
bot.sendGroupMarkdown(groupId, "**markdown**");
bot.sendGroupImage(groupId, url);
```

## 七、框架能力：PluginServices（动作）

插件方法注入 `PluginServices svc` 即可调用框架全部能力。

> ⚠️ **多机器人必看**：主动发送/查群信息/群管动作时，`botKey` 必须传**事件所属机器人**（`bot.selfId()` 或 `e.getBotId()`）。传空串会回退到第一个机器人，导致发错群（QQ 报 11255）。

### 7.1 发送消息

#### `XuanJiSendReceipt sendToGroup(String botKey, String groupOpenid, XuanJiMessage chain)`

| 参数 | 类型 | 说明 |
|---|---|---|
| botKey | String | 机器人标识 |
| groupOpenid | String | 群 openid |
| chain | XuanJiMessage | 消息链（文本/markdown/富媒体/按钮） |

返回值 `XuanJiSendReceipt`：`success()` 是否成功 / `platformMsgId()` 平台消息 ID / `errorMessage()` 失败原因

#### `XuanJiSendReceipt sendToPrivate(String botKey, String openid, XuanJiMessage chain)`

同上，单聊场景（openid = 用户 openid）。

### 7.2 LLM 对话

```java
String chat(String user);            // 单轮对话（默认模型）
String chat(String system, String user); // 带系统指令
```

> 使用全局配置的默认供应商/模型；429/5xx 等瞬态错误框架自动重试。

### 7.3 群管命令（返回 OpResult）

> **OpResult**：`ok()` 是否成功；`message()` 成功提示或失败原因。失败原因由框架/适配器提供，可精确定位问题（如"机器人必须为群管理"、"不能禁言群主或管理员"、"QQ平台错误 [10013] …"）。

#### `OpResult approveGroupJoin(botKey, groupOpenid, memberOpenid, joinRequestId, approve, reason)`

| 参数 | 类型 | 说明 |
|---|---|---|
| memberOpenid | String | 申请者 openid |
| joinRequestId | String | 申请 ID（**必传**，来自 `getJoinRequestInfo().joinRequestId()` 或列表查询） |
| approve | boolean | true=同意 false=拒绝 |
| reason | String | 拒绝理由（拒绝时可选） |

#### `OpResult muteGroupMember(botKey, groupOpenid, memberOpenid, int minutes)`

`minutes` 禁言分钟数（**<=0 解除禁言**；分钟→秒由适配器换算）。

#### `OpResult muteGroupMembers(botKey, groupOpenid, List<String> memberOpenids, int minutes)`

批量禁言（一个失败不影响其它），成功含"已禁言 N 人"，失败含成员级明细。

#### `OpResult recallGroupMessage(botKey, groupOpenid, String msgId)`

撤回群消息。

#### `OpResult recallRecentMessages(botKey, groupOpenid, memberOpenid)` / `(botKey, groupOpenid, memberOpenid, int count)`

撤回该成员最近 N 条消息（无 count 默认 **1 条**；count 上限 50）。框架负责：权限校验（机器人须群管理）→ 查最近消息 → **2 分钟窗口**判断（超时跳过）→ 逐条撤回并汇总。成功含"已撤回 N 条，跳过 M 条（超2分钟或平台拒绝）"。

#### `OpResult recallPrivateMessage(botKey, openid, String msgId)`

撤回单聊消息。

### 7.4 平台信息查询（类型化返回；null / 空列表 = 平台不支持或失败）

| 方法 | 返回类型 | 说明 |
|---|---|---|
| `getGroupInfo(botKey, groupOpenid)` | `GroupInfo` | 群信息（远程平台 API，实时） |
| `getLocalGroupInfo(botKey, groupOpenid)` | `GroupInfo` | 群信息（查本地库，**高频用**，免限频） |
| `getBotGroupState(botKey, groupOpenid)` | `BotGroupState` | 机器人在群内状态 |
| `getGroupMuteStatus(botKey, groupOpenid)` | `GroupMuteStatus` | 群禁言状态 |
| `listGroupJoinRequests(botKey, groupOpenid)` | `JoinRequestList` | 入群申请列表（含 next_cursor） |
| `listGroupMembers(botKey, groupOpenid)` | `List\<GroupMember\>` | 群成员列表（本地库） |
| `listGroups(botKey)` | `List\<GroupInfo\>` | 机器人所在群列表（本地库） |
| `getGroupBotRole(botKey, groupOpenid)` | `GroupBotRole` | 机器人在群内角色 |
| `listUsers(botKey)` | `List\<UserInfo\>` | 单聊用户列表（本地库） |

**类型化对象字段**：

| 对象 | 字段 / 便捷方法 |
|---|---|
| `GroupInfo` | `groupId` / `groupName` / `ownerId` / `memberCount` / `memberMax` / `found` |
| `BotGroupState` | `botState`（1=正常 2=被移出 3=群解散 4=被禁言）/ `isOnline()` / `groupName` / `memberCount` |
| `GroupMuteStatus` | `muteExpireAt` / `muteSecondLeft` / `isMuted()` |
| `GroupMember` | `memberId` / `nickname` / `role` / `joinTime` |
| `UserInfo` | `userId` / `nickname` / `remark` / `unionOpenid` / `joinTime` |
| `GroupBotRole` | `role` / `isOwner()` / `isAdmin()` / `isManager()` |
| `JoinRequest` | 见「5.6 入群申请事件」 |
| `JoinRequestList` | `requests()` / `nextCursor()` / `isEmpty()` / `size()` |

> 所有类型化对象都有 `raw()` 返回平台原始 Map，平台字段扩展时仍可读取完整数据。

### 7.5 底层动作（PlatformActions）

`PluginServices` 已封装全部动作，插件一般无需直接使用。`PlatformActions` 定义 14 个动作常量（供框架内部按平台适配器路由）：

| 常量 | 值 | 说明 |
|---|---|---|
| `GROUP_INFO` | group.info | 群基本信息（远程） |
| `GROUP_LOCAL_INFO` | group.local_info | 群本地档案（查库免限频） |
| `GROUP_BOT_STATE` | group.bot_state | 机器人群内状态 |
| `GROUP_MUTE` | group.mute | 群成员禁言 |

## 八、持久化存储（PluginStorage）

落库 `xuanji_plugin_kv`，按插件 ID 隔离，key 自己带业务维度：

```java
@Command(value = "签到", scope = Command.Scope.GROUP)
public String sign(GroupMessageEvent e, PluginStorage store) {
    String uid = e.getSenderId();
    long n = store.getLong("coins:" + uid, 0) + 1;
    store.set("coins:" + uid, String.valueOf(n));
    return "累计签到 " + n + " 次";
}
```

## 十、注解全表

### 插件级：@XuanJiPlugin

| 字段 | 说明 |
|---|---|
| id | 插件唯一 ID（**必填**） |
| name / version / author / description | 插件元信息 |
| permissions | 权限声明：`NETWORK`(联网) / `FILESYSTEM`(读写文件) / `PROACTIVE_MESSAGE`(主动发消息) |
| dependsOn | 依赖的能力 |
| rateLimit | 消息触发频率限制（秒，0=不限制） |
| platforms | 限定平台（空=全部） |

### 命令：@Command

| 字段 | 说明 |
|---|---|
| value / cmd | 触发词（支持正则如 `"签到\|打卡"`；空串=匹配所有消息） |
| scope | `Command.Scope.GROUP` / `PRIVATE` / `BOTH`（默认） |
| roles | 限定角色，如 `{"owner","admin"}`（空=不限制） |
| at | `AtMode.IGNORE` / `NEED`(必须@机器人) / `NOT`(不能@机器人) |
| order | 优先级 |
| groups / senders | 限定群 / 限定发送者 |
| startWith / endWith | 前缀 / 后缀触发 |
| media / mediaTypes | 富媒体过滤（`NEED` / `NOT` / `IGNORE`） |
| platforms / invert | 限定平台 / 反转过滤 |

### 命令参数：@Arg

`value`(参数名) / `required`(必填，默认 true) / `missing`(缺参提示) / `rest`(取剩余全部含空格，仅最后一个 @Arg)

### 消息监听

| 注解 | 用途 | 字段 |
|---|---|---|
| `@GroupMessage` | 收到群聊消息 | `order` / `platforms` |
| `@PrivateMessage` | 收到单聊消息 | `order` / `platforms` |
| `@OnMessage` | 底层原始消息监听（自动回复/日志/风控） | `type` / `priority` / `block`(阻断后续链) / `groupOnly` / `privateOnly` |

### 事件监听

| 注解 | 用途 | 字段 |
|---|---|---|
| `@GroupEvent` | 群系统事件 | `order` / `platforms` |
| `@PrivateEvent` | 私聊系统事件 | `order` / `platforms` |

### 消息过滤：@MessageFilter

`cmd` / `startWith` / `endWith` / `at` / `groups` / `senders` / `roles` / `platforms` / `media` / `mediaTypes` / `invert`

### 权限与限流

| 注解 | 用途 | 字段 |
|---|---|---|
| `@RequireRole` | 权限要求（裁决：黑名单 → 特权 → 平台角色 → 权限点） | `value`(BOT_MASTER/SUPER_ADMIN/OWNER/ADMIN/MEMBER) / `permissions`(权限点，OR) |

| `@PrivateOnly` | 仅私聊响应（与 @GroupOnly 互斥） | — |

## 十一、内嵌键盘按钮（Keyboard）

按钮挂载在 markdown 消息下（`content.rows[].buttons[]` 结构原样透传）。核心字段：

- `action.type`：0=跳转(URL) / 1=回调(data 回传后台) / 2=指令(输入框插入 @bot data)
- `render_data.style`：0=灰线框 1=蓝线框 2=白字 3=蓝底白字；`label`≤10 字
- `permission.type`：0=指定用户(specify_user_ids) / 1=仅管理员 / 2=所有人
- `visited_label`：点击后按钮文字（**建议必配**，否则点击后按钮文字清空）

> ⚠️ **实测结论**：`permission` 必传（不传点击一律"无权限操作"）；回调按钮点击触发 `INTERACTION_CREATE` 事件（框架已自动回应），跳转按钮不触发；指令按钮正常插入 @bot data。
> 完整字段、官方错误码、Java 构建示例见 **《QQ内嵌键盘按钮使用指南.md》**。

## 十四、Maven 依赖引入（推荐方式）

**v1.3.1 起，框架 SDK 已发布到 CNB 公开 Maven 制品库，插件开发者无需手动下载 sdk/api jar，直接 Maven 依赖即可：**

```xml
<!-- 插件 pom.xml：声明 CNB 制品库 + 两个依赖 -->
<project>
    <repositories>
        <repository>
            <id>cnb-xuanji-api</id>
            <name>CNB XuanJi API Registry</name>
            <url>https://maven.cnb.cool/XuanJiBot/xuanji-api/-/packages/releases</url>
        </repository>
        <repository>
            <id>cnb-xuanji-sdk</id>
            <name>CNB XuanJi SDK Registry</name>
            <url>https://maven.cnb.cool/XuanJiBot/xuanji-sdk/-/packages/releases</url>
        </repository>
    </repositories>

    <dependencies>
        <!-- API 注解/类型化对象/事件接口（插件开发用） -->
        <dependency>
            <groupId>dev.xuanji</groupId>
            <artifactId>xuanji-api</artifactId>
            <version>1.3.1</version>
            <scope>provided</scope>
        </dependency>
        <!-- SDK 便捷工具（事件/消息构建等） -->
        <dependency>
            <groupId>dev.xuanji</groupId>
            <artifactId>xuanji-sdk</artifactId>
            <version>1.3.1</version>
            <scope>provided</scope>
        </dependency>
        <!-- PF4J 基类 -->
        <dependency>
            <groupId>org.pf4j</groupId>
            <artifactId>pf4j</artifactId>
            <version>3.15.0</version>
            <scope>provided</scope>
        </dependency>
    </dependencies>
</project>
```

**要点：**
- `scope=provided` 保持不变：插件 jar 不打包这些依赖，运行时由框架核心 ClassLoader 提供
- 版本必须写具体值（`1.3.1`），不能写 `latest`；如需跟随最新可用：`[1.3.1,)` 版本范围
- 两个制品库（xuanji-api / xuanji-sdk）都要声明为 repository，sdk 模块会传递依赖 api
- 当前版本 `1.3.1`，后续框架升级后更新版本号即可

> 若仍想手动管理 jar：把 `xuanji-api-1.3.1.jar` 与 `xuanji-sdk-1.3.1.jar` 下载到 `lib/` 并用 `systemPath` 引入，但不推荐。
