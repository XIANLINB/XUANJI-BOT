# 小白部署指南 · 零环境开箱即用

> 目标用户：**完全不懂代码 / 没装 Java 的用户**。只需下载、启动、配置，全程不碰代码。

---

## 一、交付物形态

框架提供一个**自带运行环境**的发布包（zip），解压后目录结构：

```
xuanji-发布包/
├── 启动.bat            ← Windows 双击即启动
├── start.sh            ← Linux/macOS 终端执行
├── xuanji-bot.jar      ← 框架本体（内置全部功能）
├── runtime/            ← 裁剪版 Java 运行环境（无需安装 JDK，约 60MB）
├── plugins/            ← 插件目录（把 .jar 放进来即可）
│   └── README.txt
├── 使用说明.txt        ← 给小白看的说明
├── data/               ← （首次启动自动生成）数据/数据库/媒体
└── logs/               ← （首次启动自动生成）运行日志
```

**用户什么都不用装**：runtime/ 里已经带了一个精简的 Java 21 运行时（由 `jlink` 裁剪，只包含框架所需模块，体积比完整 JDK 小 80%）。

## 二、打包机操作（开发者做一次）

前提：打包机装有 JDK 21+（仅打包时需要，发布后的用户不需要）。

```bash
# 双击运行（或命令行）
打包发布包.bat
```

脚本自动完成：
1. `mvn clean package` 编译全量
2. `jdeps` 分析运行期需要的 JDK 模块
3. `jlink` 生成裁剪运行时 → `release/dist/runtime/`
4. 组装 `release/dist/` 完整目录 + 启动脚本 + 使用说明
5. 产出 `release/dist/` → 压缩成 `xuanji-发布包.zip` 交付

> 跨平台：Windows 上打包的 runtime 只给 Windows 用；Linux/macOS 用户需在对应平台重新打包一次（或交付源码让用户自行构建）。

---

## 三、用户操作（3 步完成）

1. **解压** `xuanji-发布包.zip`（任意目录，路径别带中文更稳妥）
2. **双击 `启动.bat`** → 黑窗口显示「启动中...」→ 浏览器自动打开控制台
   - Linux/macOS：终端执行 `./start.sh`
3. **首启向导**：填入 QQ 机器人 AppID / AppSecret / Token → 保存
   - 没有机器人？到 [QQ 开放平台](https://q.qq.com) 注册（免费），按平台指引创建
   - 也支持 OneBot 接入（NapCat 等），见 `docs/onebot-napcat-guide.md`

完事。机器人上线后群里就能聊了。

## 四、日常使用

| 想做什么 | 怎么做 |
|---|---|
| 加插件 | 插件 `.jar` 拖进 `plugins/` → 控制台「插件」页点**热加载**（不重启） |
| 管理机器人 | 控制台「机器人」页：添加 / 删除 / 切换连接模式 |
| 改配置 | 控制台「运行设置」：全局 / 机器人 / 群 三级，即时生效 |
| 看消息 | 控制台「消息」页：群消息 / 私聊，收/发方向 |
| 拉黑人 | 控制台「权限」页：主人 / 黑名单 |
| 升级框架 | 下载新版发布包 → 覆盖 `xuanji-bot.jar` → 重启。**数据不丢**（见升级指南） |

## 五、实现原理（开发者视角）

| 技术 | 作用 |
|---|---|
| `jlink` | 从 JDK 裁剪出「只含所需模块」的运行时，体积从 ~300MB 降到 ~60MB |
| `jdeps` | 自动分析 fat jar 依赖的 JDK 模块，保证裁剪不残缺 |
| Spring Boot fat jar | 单 jar 包含全部依赖，`java -jar` 直接跑 |
| 首启向导 | 框架内置 `SetupController`，首次启动引导配置机器人 |
| 热加载 | `CopyingJarPluginLoader` + `reloadJar()`，插件更新不重启 |

**备选方案**（如需更专业的安装体验）：
- `jpackage --type app-image`：生成原生 `.exe`/`.app` 应用图标 + 自带运行时（同样零依赖）
- `jpackage --type msi/exe`：生成安装程序，用户一键安装、桌面快捷方式
- 未来可配合 GitHub Actions 自动构建三平台发布包

---

## 六、注意事项

- 发布包**不含** `data/`（用户首次启动自动生成）——确保交付 zip 干净
- 若用户机器已有 Java，可删掉 `runtime/` 直接 `java -jar xuanji-bot.jar`（可选优化）
- Windows Defender 可能对 `.bat`/`.jar` 弹提示，属正常（自用软件），选择「仍要运行」
