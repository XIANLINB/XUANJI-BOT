# 璇玑（XuanJi）使用手册

> 面向最终用户：从下载发布包到日常使用 Web 控制台的全流程说明。
> 面向开发者请阅读《插件开发完整指南》与《架构说明》。

---

## 一、项目简介

璇玑是一个**多机器人、多平台**的 QQ 机器人框架，内置完整 Web 控制台（全中文界面）。核心特点：

- **一个框架管理 N 个机器人**：各自独立配置、独立落库、互不影响
- **零代码配置**：通过控制台可视化添加/管理机器人，无需写任何代码
- **AI 能力内置**：AI 对话、人格扮演、长期记忆、工具调用、意图路由、定时任务、知识库、AI 审核
- **插件扩展**：`@Command` 注解一行注册命令，支持热加载（改插件不重启）
- **数据本地化**：所有数据（消息、配置、日志）存储在本地，无需外部数据库

## 三、快速开始

### 步骤 1：下载发布包

从发布渠道下载对应平台的发布包：

- `xuanji-<版本>-win.zip` —— Windows 平台
- `xuanji-<版本>-linux.tar.gz` —— Linux 平台

发布包已内置精简 JRE，**无需预装 JDK**。

### 步骤 2：解压

Windows：解压 zip 到任意目录（路径不要含中文与空格，避免兼容问题）。

Linux：

```bash
tar -xzf xuanji-<版本>-linux.tar.gz
cd xuanji
```

### 步骤 3：启动

**Windows**：双击 `启动.bat`（或在命令行执行）：

```bat
启动.bat
```

**Linux**：

```bash
./start.sh
```

启动成功后控制台会打印：

```
==========================================================
  [璇玑] 控制台已就绪，请访问:
    🖥 控制台:   http://localhost:8668/xuanji/console/
    🩺 健康检查: http://localhost:8668/xuanji/api/v1/console/health
==========================================================
```

浏览器打开 **http://localhost:8668/xuanji/console/** 即可进入控制台。

> 默认端口 8668，可通过环境变量 `SERVER_PORT` 修改（如 `SERVER_PORT=9000`）。

### 步骤 4：首次引导

首次访问控制台会进入引导流程（`/setup`），按提示完成：

1. **设置管理口令（PIN）**：设置 6 位以上 PIN，之后进入控制台需验证。PIN 使用 PBKDF2 哈希存储，无法找回，**请牢记**。
2. **添加 QQ 机器人**：填入在 [QQ 开放平台](https://q.qq.com) 创建的机器人信息：
   - `AppID`
   - `AppSecret`（保存时自动加密落盘，不存明文）
   - `Token`
   - 选择接入模式：**WebSocket**（推荐，无需公网）或 **Webhook**（需公网回调）
   - 测试机器人（沙箱）需勾选沙箱环境选项
3. **完成**：引导完成后机器人自动上线，群里即可使用。

> 机器人如何创建：在 QQ 开放平台「应用管理 → 创建机器人」获取 AppID / AppSecret / Token，并配置事件订阅（如「消息与群聊事件」）。

## 四、Web 控制台使用指南

控制台所有功能按左侧导航分组，全中文界面，实时数据自动刷新。

### 4.1 仪表盘

- 机器人概览：在线状态、消息收发量、活跃群数
- 消息趋势图：按小时/天统计入站/出站消息
- 运行状态：JVM 内存、线程、QPS 等
- 框架版本日志：v0.1.0 ~ 当前版本的更新时间线

### 4.2 机器人管理

- **添加机器人**：接入 QQ 开放平台机器人（AppID / AppSecret / Token）
- **机器人列表**：每个机器人显示在线状态、接入模式（WS/Webhook）、版本
- **机器人详情**：
  - 基本信息查看与编辑（AppSecret 加密存储，只显示掩码）
  - **分享链接生成**：输入回调数据，生成 `qrobot://` 分享链接，可发给好友/群一键唤起机器人
- **删除机器人**：删除前需确认（数据保留在实例库中）

### 4.3 消息监控

- **群消息**：实时滚动展示各群消息，支持按群筛选、查看发送者、消息时间
- **单聊消息**：实时展示用户与机器人的私聊消息
- **聊天窗口**：点击消息可进入该会话，查看完整对话上下文

### 4.4 群聊 / 单聊管理

- **群列表**：机器人所在群，显示群名、成员数、机器人群内角色
- **群成员**：查看成员列表（昵称、角色、入群时间），支持群成员禁言等管理操作（需机器人是群管理）
- **好友列表**：与机器人有单聊的用户，可查看备注、最近互动
- **操作日志**（群聊管理下）：群管理动作审计，记录 谁/何时/对谁/做了什么（禁言、撤回、审批等），支持按操作人、操作类型、群、时间范围筛选与搜索

### 4.5 插件管理

- **插件列表**：已安装插件（`plugins/` 目录中的 jar），显示 ID、名称、版本、启用状态
- **启用 / 停用**：一键启停插件
- **热加载**：修改插件代码重新打包后，点「热加载」即可生效，**无需重启框架**
- **插件配置**：插件若实现配置面板，可在此填写表单配置项
- **插件市场**：浏览/管理可用的插件包

### 4.6 定时任务

- 可视化 cron 任务管理：创建、编辑、暂停、删除
- 支持定时推送消息到群/用户、定时执行 HTTP 请求等
- 支持"自然语言建定时"（AI 对话中直接说"每周五 15:00 提醒我喝水"）

### 4.7 权限 / 安全

- **权限管理**：主人（master）、超级管理员、管理员角色配置；群级/用户级黑名单
- **安全设置**：PIN 修改、会话管理、审计日志
- **操作日志**：框架级操作审计（登录、机器人操作、审批等）
- 安全机制：PIN 登录（PBKDF2 哈希）、Webhook 事件 Ed25519 签名验签、黑名单一票否决

### 4.8 数据

- **数据库浏览**：在线浏览框架库表数据（群、用户、消息、插件 KV 等）
- **备份恢复**：一键导出全部数据为 zip；恢复前自动创建快照，可回滚
- **缓存管理**：查看/清理框架内存缓存

### 4.9 AI 能力

| 页面 | 功能 |
|---|---|
| AI 设置 | 默认供应商/模型、对话开关、全量接话/仅 @机器人 等 |
| AI 对话 | 与机器人对话调试 |
| 人格管理 | 创建/切换人格（内置"落落""清璃"模板），人格影响回复风格 |
| 用量统计 | 模型调用次数、Token 消耗 |
| 工具管理 | 内置工具（查时间/查天气/掷骰子/群统计…）启停 |
| MCP 接入 | 配置外部 MCP 服务，扩展工具库 |
| 知识库 | 上传文档构建 RAG，机器人基于知识库回答 |
| AI 审核 | 消息过 LLM 审核，违规自动拦截 |
| AI 日报 | 自动生成群聊/统计日报 |
| 记忆管理 | 查看/清理 AI 长期记忆（跨重启保留） |
| 供应商管理 | 配置多家 LLM 供应商（OpenAI 兼容协议等） |

### 4.10 系统监控

- 健康检查：框架健康、数据库连接、QQ 连接状态
- 监控指标：JVM、线程池、QPS、消息趋势
- 系统日志：`logs/xuanji-bot.log` 在线查看，支持按级别筛选
- 告警中心：风险事件与告警列表

## 五、目录结构与数据

解压后目录结构：

```
xuanji/
├── 启动.bat / start.sh   # 启动脚本（Windows / Linux）
├── jre/                  # 内置精简 Java 运行时（无需预装 JDK）
├── lib/                  # 框架 fat jar
├── plugins/              # 插件目录：把插件 .jar 放这里
├── data/                 # 运行数据（自动生成）
│   ├── xuanji-robots.yml # 机器人配置（控制台写入，含加密的 AppSecret）
│   ├── xuanji/data/      # 框架库（H2）
│   ├── xuanji/xuanji.log.mv.db  # 日志库（H2）
│   └── qqbot/<appid>/    # 每个机器人独立实例库（H2）
└── logs/                 # 运行日志
    └── xuanji-bot.log
```

**数据安全提示**：
- 所有数据默认存在 `data/` 目录，**备份时请整体打包 `data/`**
- 机器人 AppSecret 经加密后存储，不会以明文出现
- 卸载/迁移时，拷贝整个发布包目录即可（含 `data/`）

## 六、常见问题（FAQ）

**Q1：启动后控制台打不开？**
先确认启动窗口是否打印了"控制台已就绪"；再检查端口 8668 是否被占用（可用 `netstat -ano | findstr 8668` 查看）。被占用时可设环境变量 `SERVER_PORT` 换端口。

**Q2：机器人添加后显示离线/连接失败？**
- 检查 AppID / AppSecret / Token 是否正确
- 测试机器人必须勾选"沙箱环境"
- 检查 QQ 开放平台的事件订阅配置是否开启了需要的消息类型
- 查看 `logs/xuanji-bot.log` 中的 `[FLOW]` 日志定位原因

**Q3：修改了插件代码但群里命令没变化？**
请确认：重新 `mvn package` 打包 → 覆盖 `plugins/` 目录中的 jar → 控制台「插件管理」点**热加载**（或重启框架）。

**Q4：如何修改机器人配置？**
在控制台「机器人管理」编辑，或直接编辑 `data/xuanji-robots.yml`（改完重启生效）。

**Q5：Webhook 模式要求什么？**
需要公网可访问的回调地址，并在 QQ 开放平台配置回调 URL；框架会校验平台签名（Ed25519）与 `X-Trace-ID` 去重。

**Q6：忘记管理 PIN 怎么办？**
PIN 无法找回。可直接删除控制台数据库 `data/xuanji/data/` 后重启（会清空框架库配置，需重新引导；机器人实例库 `data/qqbot/` 不受影响）。

**Q7：如何彻底备份/迁移？**
停止框架 → 复制整个目录 → 在新的机器上启动即可。在线备份也可用控制台「数据 → 备份恢复」。

## 七、高级：源码运行（开发者）

```bash
# 环境：JDK 25+、Maven 3.9+
mvn clean package -DskipTests
cd xuanji-starter
java -jar target/xuanji-starter-<版本>.jar
```

IDEA 可直接运行 `XuanJi.starter.XuanJiApplication` 主类。

> 注意：源码运行方式下插件打包、前端产物同步等请参考《插件开发完整指南》与仓库 `scripts/` 目录说明。
